# Tabler icons (outline + filled)

From `@tabler/icons` 3.24.0 (https://tabler.io/icons), MIT licence (`LICENSE`). Repacked:
`outline.json` / `filled.json` map an icon name to its SVG nodes (`[["path", {"d": …}], …]`,
24 × 24 viewBox, 2 px round strokes); `tags.json` maps a name to its search tags. Drawn by
`konvey/stage/icons.py`.
